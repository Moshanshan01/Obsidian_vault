# 使用 OpenSSL 命令实现加解密与签名

> OpenSSL 是 PC 端的密码学工具，用于开发调试时手动加密/签名/哈希固件，验证 STM32 端 mbedTLS 实现是否正确。设备端对应的库是 [[6. 使用mbedTLS实现上述|mbedTLS]]。

---

## 安装
```bash
# OpenSSL：命令行加解密、生成密钥、计算哈希，调试必备 
sudo pacman -S openssl
```

## 常用 OpenSSL 命令

```bash
# 计算文件 SHA256
openssl dgst -sha256 firmware.bin

# AES-128-CBC 加密固件
openssl enc -aes-128-cbc -in firmware.bin -out firmware.enc \
    -K 0123456789ABCDEF0123456789ABCDEF \
    -iv 00000000000000000000000000000000

# 解密验证
openssl enc -d -aes-128-cbc -in firmware.enc -out firmware_dec.bin \
    -K 0123456789ABCDEF0123456789ABCDEF \
    -iv 00000000000000000000000000000000

# 生成 RSA 密钥对（仅学习参考，OTA 实际用 ECDSA）
openssl genrsa -out private.pem 2048
openssl rsa -in private.pem -pubout -out public.pem

# 生成 ECC 密钥对（OTA 实际使用，对应 STM32 端 SECP256R1）
openssl ecparam -genkey -name prime256v1 -out ec_private.pem
openssl ec -in ec_private.pem -pubout -out ec_public.pem

# 对固件签名（用 ECC 密钥）
openssl dgst -sha256 -sign ec_private.pem -out firmware.sig firmware.bin

# 验证签名（用 ECC 公钥）
openssl dgst -sha256 -verify ec_public.pem -signature firmware.sig firmware.bin
```

这些命令在 PC 端验证你的 STM32 加解密实现是否正确，非常实用。

## Python 打包脚本

用 OpenSSL 命令行手动打包，但每次发布固件要敲很多命令，容易出错。补充一个 Python 脚本自动完成整个 PC 端流程：

```python
# pack_firmware.py
# 用法：python pack_firmware.py firmware.bin ec_private.pem output.pkg
# 这个脚本把 SHA256、签名、AES 加密、打包头全部一键完成，开发测试时省很多时间。

import struct, hashlib, subprocess, sys
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad

def pack_firmware(bin_path, key_path, output_path):
    KEY = bytes.fromhex("0123456789ABCDEF0123456789ABCDEF")  # 实际从安全存储读取
    IV  = bytes(16)  # 实际随机生成：os.urandom(16)

    # 1. 读取原始固件
    with open(bin_path, "rb") as f:
        firmware = f.read()
    firmware_size = len(firmware)

    # 2. 计算 SHA256（填充前的原始固件）
    sha256 = hashlib.sha256(firmware).digest()

    # 3. ECDSA 签名
    result = subprocess.run([
        "openssl", "dgst", "-sha256",
        "-sign", key_path,
        "-out", "/tmp/firmware.sig",
        bin_path
    ], check=True)
    with open("/tmp/firmware.sig", "rb") as f:
        signature_der = f.read()
    # DER 格式签名需要转成 r+s 64字节格式，实际项目注意对齐
    signature = signature_der[:64].ljust(64, b'\x00')

    # 4. AES-CBC 加密
    cipher = AES.new(KEY, AES.MODE_CBC, IV)
    ciphertext = cipher.encrypt(pad(firmware, 16))

    # 5. 构造固件头（128字节）
    # magic(4) + version(4) + firmware_size(4) + iv(16) + sha256(32) + signature(64) + crc(4)
    VERSION = 2
    header_without_crc = struct.pack("<4sII16s32s64s",
        b"FWPK", VERSION, firmware_size, IV, sha256, signature)

    import binascii
    crc = binascii.crc32(header_without_crc) & 0xFFFFFFFF
    header = header_without_crc + struct.pack("<I", crc)

    # 6. 写出固件包
    with open(output_path, "wb") as f:
        f.write(header)
        f.write(ciphertext)

    print(f"打包完成：{output_path}")
    print(f"原始大小：{firmware_size} 字节")
    print(f"包大小：{len(header) + len(ciphertext)} 字节")
    print(f"SHA256：{sha256.hex()}")
```
