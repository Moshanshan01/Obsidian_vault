# 使用 mbedTLS 实现加解密与验签

> mbedTLS 是 ARM 官方的轻量级 TLS/加密库，专为嵌入式设计。在 OTA 中用于 STM32 端的所有密码学操作。PC 端对应工具是 [[7. 使用OpenSSL命令实现上述|OpenSSL]]。
>
> 截至 2026 年，最新版 mbedTLS 架构已变化（加密模块迁移到 tf-psa-crypto 子仓库），建议使用 3.6 LTS 版本：
> ```bash
> git clone -b mbedtls-3.6 https://gitee.com/tianbeibei/mbedtls.git
> ```

## AES-CBC 加解密

```c
#include "mbedtls/aes.h"

// ===== 密钥和 IV =====
// 实际项目中密钥存 OTP（一次性可编程区，写后不可改），IV 随机生成每次不同
uint8_t key[16]     = {0x01,0x02,...};  // 128bit 密钥
uint8_t iv[16]      = {0x00,0x00,...};  // 初始向量
uint8_t iv_copy[16];                    // CBC 会修改 iv，必须备份原始值

// ===== 加密 =====
mbedtls_aes_context aes;
mbedtls_aes_init(&aes);                          // 初始化上下文（置零）
mbedtls_aes_setkey_enc(&aes, key, 128);          // 设置加密轮密钥

memcpy(iv_copy, iv, 16);                         // ⚠️ 必须备份 iv，函数会修改它
mbedtls_aes_crypt_cbc(&aes,
    MBEDTLS_AES_ENCRYPT,
    plaintext_len,    // ⚠️ 必须是16字节的整数倍，不是则需要PKCS7填充后再传入
    iv_copy,          // 输入：初始向量；输出：最后一块密文（被修改了）
    plaintext,
    ciphertext);

mbedtls_aes_free(&aes);  // 释放上下文，清除密钥等敏感信息

// ===== 解密（必须重新 init，free 后不能直接 setkey）=====
mbedtls_aes_init(&aes);
mbedtls_aes_setkey_dec(&aes, key, 128);  // 解密轮密钥（从加密密钥逆推）
memcpy(iv_copy, iv, 16);                  // 使用原始 iv（不是加密结束时的 iv_copy）
mbedtls_aes_crypt_cbc(&aes,
    MBEDTLS_AES_DECRYPT,
    ciphertext_len,
    iv_copy,
    ciphertext,
    plaintext);
mbedtls_aes_free(&aes);
```

> ⚠️ **PKCS7 填充提醒**（详见 [[4. AES 原理（解决保密性）]]）：
> - 加密前数据必须是16字节整数倍，不足则填充
> - 即使数据长度正好是16的整数倍，PKCS7 依然会追加16字节的 `0x10`
> - 解密后必须按 `firmware_size`（原始大小）截断，去掉填充字节，再做 SHA256

## SHA256 计算

```c
#include "mbedtls/sha256.h"

uint8_t digest[32];  // SHA256 输出固定 32 字节

mbedtls_sha256_context sha;
mbedtls_sha256_init(&sha);
mbedtls_sha256_starts(&sha, 0);  // 0 = SHA256，1 = SHA224

// 支持分块喂数据，适合大固件
mbedtls_sha256_update(&sha, data, data_len);
// 大固件示例：
// while (还有数据) { mbedtls_sha256_update(&sha, block, block_len); }

mbedtls_sha256_finish(&sha, digest);
mbedtls_sha256_free(&sha);

// digest 现在是 32 字节 SHA256 摘要
// ⚠️ 这个 digest 后续会作为 ECDSA 验证的输入参数传入
```

## ECDSA 签名验证

> ⚠️ **阅读前必须理解**：ECDSA 验证和 RSA 验证有本质区别。
> RSA 可以从签名里"解出"哈希值，ECDSA 不能——哈希值必须作为**输入**传给验证函数。
> 如果不理解这个区别，下面代码中 `digest` 参数的作用会让你困惑。
> 详见 [[5. ECDSA数字签名原理（解决真实性）]]。

```c
#include "mbedtls/ecdsa.h"
#include "mbedtls/ecp.h"

// ===== 前置步骤：必须先算好 SHA256 =====
// ECDSA 验证需要 hash 作为数学运算的输入（不是用来"比对"的）
// 所以必须在调用 ecdsa_read_signature 之前自己算好 digest
uint8_t digest[32];
// ...（上面 SHA256 部分的代码算出 digest）...

// ===== ECDSA 验证 =====
mbedtls_ecdsa_context ecdsa;
mbedtls_ecdsa_init(&ecdsa);

// 加载内置公钥（SECP256R1 曲线，对应 OpenSSL 的 prime256v1）
mbedtls_ecp_group_load(&ecdsa.grp, MBEDTLS_ECP_DP_SECP256R1);
mbedtls_ecp_point_read_binary(&ecdsa.grp, &ecdsa.Q,
    public_key_bytes,       // 04 开头的非压缩格式公钥，65字节
    public_key_len);        // 65

// 验证签名
// ⚠️ digest 是 ECDSA 数学验证（u1*G + u2*Q）的必要输入
//    不是可选参数，也不是"用来比对"的——是参与椭圆曲线点运算的核心数据
//    如果传错 digest（比如传全零），验证会失败或产生错误结果
int ret = mbedtls_ecdsa_read_signature(&ecdsa,
    digest,          // ← SHA256 摘要，ECDSA 验证的数学输入（非常关键）
    32,
    signature,       // 固件头里的 signature[64]（DER 格式或 r+s 格式）
    signature_len);

if (ret == 0) {
    // 验签通过：签名有效，固件确实来自持有私钥的合法发布者
} else {
    // 验签失败：可能是固件被篡改，或签名字段损坏，或公私钥不匹配
}

mbedtls_ecdsa_free(&ecdsa);
```

## mbedTLS 集成到 CMake

`mbedtls_config.h` 控制哪些模块编译进去，默认全量编译会超出 Flash。建议新建 `my_mbedtls_config.h` 只开启 OTA 需要的模块：

```cmake
# CMakeLists.txt
set(MBEDTLS_DIR ${CMAKE_SOURCE_DIR}/Middlewares/mbedtls)

# 只编译 OTA 需要的模块（AES + SHA256 + ECDSA）
set(MBEDTLS_SRCS
    ${MBEDTLS_DIR}/library/aes.c
    ${MBEDTLS_DIR}/library/sha256.c
    ${MBEDTLS_DIR}/library/ecdsa.c
    ${MBEDTLS_DIR}/library/ecp.c
    ${MBEDTLS_DIR}/library/ecp_curves.c
    ${MBEDTLS_DIR}/library/bignum.c
    ${MBEDTLS_DIR}/library/platform_util.c
    ${MBEDTLS_DIR}/library/asn1parse.c
    ${MBEDTLS_DIR}/library/asn1write.c   # ECDSA 签名编码需要
)

target_sources(${CMAKE_PROJECT_NAME} PRIVATE ${MBEDTLS_SRCS})

target_include_directories(${CMAKE_PROJECT_NAME} PRIVATE
    ${MBEDTLS_DIR}/include
)

# 指定使用裁剪后的配置文件
# target_compile_definitions 等价于给每个 .c 文件顶部加 #define，全局生效
target_compile_definitions(${CMAKE_PROJECT_NAME} PRIVATE
    MBEDTLS_CONFIG_FILE="${MBEDTLS_DIR}/include/mbedtls/my_mbedtls_config.h"
)
```

**my_mbedtls_config.h 最小配置：**

```c
/* OTA 场景最小配置：AES-CBC + SHA256 + ECDSA 验签 */

/* 平台基础 */
#define MBEDTLS_PLATFORM_C
#define MBEDTLS_PLATFORM_MEMORY

/* AES-CBC */
#define MBEDTLS_AES_C
#define MBEDTLS_CIPHER_C
#define MBEDTLS_CIPHER_MODE_CBC

/* SHA256 */
#define MBEDTLS_SHA256_C
#define MBEDTLS_MD_C

/* ECDSA 验签（SECP256R1 曲线）*/
#define MBEDTLS_ECP_C
#define MBEDTLS_ECP_DP_SECP256R1_ENABLED
#define MBEDTLS_ECDSA_C
#define MBEDTLS_BIGNUM_C       // ECC 依赖大数运算
#define MBEDTLS_ASN1_PARSE_C   // 签名格式解析
#define MBEDTLS_ASN1_WRITE_C   // ⚠️ 签名编码也需要，不加会编译报错

/* 关闭不需要的：TLS/SSL、X509、RSA、MD5/SHA1、网络层 */
```
