# 使用 OpenSSL 命令实现加解密与签名

> OpenSSL 是 PC 端的密码学工具，用于开发调试时手动加密/签名/哈希固件，验证 STM32 端 mbedTLS 实现是否正确。设备端对应的库是 [[6. 使用mbedTLS|mbedTLS]]。

---

## 安装
```bash
# OpenSSL：命令行加解密、生成密钥、计算哈希，调试必备 
sudo pacman -S openssl
```

## 常用 OpenSSL 命令

```bash
# 计算文件 SHA256
openssl dgst -sha256 firmware.bin

# AES-128-CBC 加密固件
openssl enc -aes-128-cbc -in firmware.bin -out firmware.enc \
    -K 0123456789ABCDEF0123456789ABCDEF \
    -iv 00000000000000000000000000000000

# 解密验证
openssl enc -d -aes-128-cbc -in firmware.enc -out firmware_dec.bin \
    -K 0123456789ABCDEF0123456789ABCDEF \
    -iv 00000000000000000000000000000000

# 生成 RSA 密钥对（仅学习参考，OTA 实际用 ECC）
openssl genrsa -out private.pem 2048
openssl rsa -in private.pem -pubout -out public.pem

# 生成 ECC 密钥对（OTA 实际使用，对应 STM32 端 SECP256R1）
openssl ecparam -genkey -name prime256v1 -out ec_private.pem
openssl ec -in ec_private.pem -pubout -out ec_public.pem

# 对固件签名
openssl dgst -sha256 -sign private.pem -out firmware.sig firmware.bin

# 验证签名
openssl dgst -sha256 -verify public.pem -signature firmware.sig firmware.bin
```

这些命令在 PC 端验证你的 STM32 加解密实现是否正确，非常实用。
