# 防降级攻击

> 即使签名有效、哈希正确，攻击者也可能截获一个旧版本的合法固件包，重新发给设备刷入（回滚攻击）。防降级机制通过版本号递增检查来阻止这种行为。

```c
// Flash 参数区存当前版本号（只能升不能降）
#define FIRMWARE_VERSION_ADDR  0x08004000  // 参数区地址

uint32_t get_current_version(void) {
    return *(uint32_t*)FIRMWARE_VERSION_ADDR;
}

// Bootloader 完整验证固件包（魔数→版本→CRC→解密→SHA256→验签）
// 注：函数名 verify_firmware 不够准确，实际做了全套验证+解密，不只是"verify"
int verify_firmware(FirmwareHeader_t *header) {
    // 1. 检查魔数
    if (memcmp(header->magic, "FWPK", 4) != 0)
        return -1;

    // 2. 检查版本（新固件版本必须大于当前版本）
    if (header->version <= get_current_version()) {
        return -2;  // 拒绝降级
    }

    // 3. 验证头部 CRC
    uint32_t crc = crc32_calc(header, sizeof(FirmwareHeader_t) - 4);
    if (crc != header->header_crc)
        return -3;

    // 4. 解密固件
    aes_decrypt(firmware_data, header->iv, decrypted_data);

    // 5. 验证 SHA256
    uint8_t digest[32];
    sha256_calc(decrypted_data, header->firmware_size, digest);
    if (memcmp(digest, header->sha256, 32) != 0)
        return -4;

    // 6. 验证签名
    if (ecdsa_verify(header->sha256, header->signature) != 0)
        return -5;

    return 0;  // 全部验证通过
}
```

### 版本号存储位置的选择

| 位置 | 优点 | 缺点 |
|------|------|------|
| Flash 参数区 | 掉电不丢，擦写寿命够用 | 需要单独管理扇区 |
| RTC 备份寄存器 | 读写简单 | 完全掉电（VBAT 也没电）时会丢失 |
| OTP 区域 | 不可篡改 | 只能写一次，无法持续更新版本号 |

> ⚠️ 不能用 RTC 备份寄存器存版本号，因为攻击者可以故意让 VBAT 掉电来绕过防降级检查。
